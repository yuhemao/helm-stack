# 个人记账本 PRD

## 目标
一个只给自己用的网页记账本：记一笔、看月度汇总、导入银行导出的 CSV。

## 技术栈
Next.js（App Router）+ Prisma + SQLite，本地运行。不换栈。

## 非目标
- 多用户、登录（本版本只在本机使用）
- 预算提醒、图表

## 功能（P0）
1. 记一笔：金额、分类、日期、备注
2. 流水列表 + 当月汇总
3. 导入 CSV（招商银行导出格式，GBK 编码）
4. 清空全部数据（设置页）
5. 深色模式（P1）

## 验收
- AC1 记一笔：输入金额 12.5、分类「餐饮」，保存后列表第一行显示「餐饮 ¥12.50」
- AC2 金额精度：所有金额按两位小数存储和显示，0.1 + 0.2 显示为 ¥0.30
- AC3 当月汇总：列表顶部显示本月支出合计，等于本月所有流水金额之和
- AC4 导入 CSV：选择一份 GBK 编码的招行 CSV，导入后列表出现对应条数，中文备注不乱码
- AC5 清空数据：在设置页点「清空全部数据」，必须二次确认；确认后列表为空，取消则数据不变
- AC6 金额必须为正数：输入 0 或负数时提示「金额必须大于 0」，不能保存
- AC7 退款：退款记为一条负数金额的流水，并从当月汇总中扣除
- AC8 深色模式：设置页切换后整站变深色，刷新后保持
