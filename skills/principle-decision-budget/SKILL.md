# Decision budget

Ask the human only for:

1. Scope do/don't
2. Conflicting user-visible behaviors
3. Money, identity, legal, irreversible data

Everything else: decide, act, report. Max 3 questions, A/B + recommendation.

Steer phrase: `apply decision-budget`
