# Token for proof

Extra inference budget buys **oracles**, not longer documents:

1. **`shape-before-code`** — settle structure before a non-trivial slice
2. **`eng-critique`** — independent engineering adversarial review
3. **`product-critique`** — product / AC adversarial review
4. **`dual-try`** — UX or eng bakeoff with shared ACs
5. **`verify-outcome`** — runnable / clickable proof loops

Do **not** spend that budget on clarifying interviews the operator cannot answer, or on document pyramids.

Steer phrase: `apply token-for-proof`
