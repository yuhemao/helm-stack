# Playbook: Change direction

For a product premise change while work is in flight.

## Steps

1. **Freeze** — Stop implementing features against the old premise.
2. **Recover posture** — Prefer `recover-wrong-turn` if docs/chat are already sprawling.
3. **Rewrite truth** — Edit `docs/helm-spec.md` so it matches the new direction. Mark removed ACs as non-goals.
4. **Invalidate** — Discard disposable plans/task lists that assumed the old premise.
5. **Reslice** — `vertical-slice` from the new spec. Identify the smallest slice that proves the new direction.
6. **Rebuild** — `build-outcome` → `verify-outcome`.
7. **Gate** — `plain-status` with assumptions you dropped.
