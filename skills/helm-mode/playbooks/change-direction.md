# Playbook: Change direction

For a product premise change while work is in flight.

## Steps

1. **Freeze** — Stop implementing features against the old premise.
2. **Recover posture** — Prefer `recover-wrong-turn` if docs/chat are already sprawling.
3. **Rewrite L0a** — Edit `docs/helm-spec.md` so it matches the new direction. Mark removed ACs as non-goals.
4. **Invalidate L1/L2** — Delete or fully rewrite `docs/helm-now.md`; discard disposable plans/task lists that assumed the old premise. Do not sync a pyramid.
5. **Reslice** — `vertical-slice` from the new contract. Identify the smallest slice that proves the new direction.
6. **Rebuild loop** — `shape-before-code` → `build-outcome` → `eng-critique` → `verify-outcome`.
7. **Gate** — `plain-status` with assumptions you dropped. Prefer a fresh thread if context is polluted.
