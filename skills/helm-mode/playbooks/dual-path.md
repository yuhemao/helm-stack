# Playbook: Dual path

High uncertainty on a user-visible approach. Buy information with two thin attempts.

## Steps

1. **Restate + constrain** — Same goal, same stack, same appetite.
2. **AC** — Write 2–4 shared observable ACs both paths must meet.
3. **Dual-try** — Run `dual-try` (two short spikes or implementations).
4. **Verify both** — `verify-outcome` rubric applied to each.
5. **Pick** — Choose by measured outcome + product judgment. Present A/B to the operator only if both pass ACs and differ on taste.
6. **Keep one** — Delete or quarantine the loser; update living spec with the chosen path; continue with normal slices.
