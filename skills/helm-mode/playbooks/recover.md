# Playbook: Recover

Doc swamp, context debt, or a bad premise. Goal: become steerable again.

## Steps

1. **Diagnose** — Name the premise failure or sprawl in one paragraph (product language).
2. **Recover** — Run `recover-wrong-turn` fully (revert → rewrite L0a → discard L1/L2 → fresh thread).
3. **Re-spec** — Ensure `docs/helm-spec.md` is a minimal thin living contract that matches what you still want.
4. **Optional** — If the operator wants to continue building, hand off to **greenfield-mvp** or **add-capability** on a **fresh thread** with only L0a + goal.
