# Playbook: Recover

Doc swamp, context debt, or a bad premise. Goal: become steerable again.

## Steps

1. **Diagnose** — Name the premise failure or sprawl in one paragraph (product language).
2. **Recover** — Run `recover-wrong-turn` fully.
3. **Re-spec** — Minimal living spec that matches what you still want.
4. **Optional** — If the operator wants to continue building, hand off to **greenfield-mvp** or **add-capability** on a fresh thread recommendation.
