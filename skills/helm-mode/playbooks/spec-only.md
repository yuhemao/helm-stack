# Playbook: Spec only

Clarify and lock the thin living product contract. Do not write product code yet.

## Steps

1. **Restate** — `restatement`.
2. **Draft** — `write-spec` (thin L0a; no tech design novel).
3. **Cut** — `cut-scope` until P0 is honest.
4. **AC harden** — Rewrite every AC as observable Given/When/Then (see terminology).
5. **Gate** — Present the contract summary and at most 3 **product** A/B questions. Wait for confirmation before any build playbook. Technical unknowns stay as model-gate assumptions, not human questions.
