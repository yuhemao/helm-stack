# Playbook: Spec only

Clarify and lock the living spec. Do not write product code yet.

## Steps

1. **Restate** — `restatement`.
2. **Draft** — `write-spec`.
3. **Cut** — `cut-scope` until P0 is honest.
4. **AC harden** — Rewrite every AC as observable Given/When/Then (see terminology).
5. **Gate** — Present the spec summary and at most 3 product A/B questions. Wait for confirmation before any build playbook.
